The native [Home Assistant](https://www.home-assistant.io/) integration for OliveTin.

This repository provides a functional HACS integration that connects Home Assistant to an OliveTin server: configure via the UI, expose argument-free actions as buttons, and start actions (including those with arguments) through the `olivetin.start_action` service, with optional wait/response data and completion events.
